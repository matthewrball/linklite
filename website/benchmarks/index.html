Sampling method

One sample per second

The sampler follows LinkLite, or DisplayLinkUserAgent and DisplayLinkXpcService, plus WindowServer for either driver. WindowServer is included because compositor work also consumes resources.

Per-process GPU time
AGX per-client AppUsage › accumulatedGPUTime counters from ioreg -r -c AGXDeviceUserClient, summed per process and differenced between samples. This is the counter behind Activity Monitor’s GPU column.
Whole-GPU utilisation
Device Utilization % in IOAccelerator performance statistics from ioreg -r -c IOAccelerator.
CPU, memory, energy impact
/usr/bin/top -l 0 -s 1 -stats command,cpu,mem,power.
Summary rule
The summary averages lite1 and lite2, and scores only desktop and animation. It is not a memory-trend detector.

Limitations

Eight-hour memory soak: not recorded
  • No eight-hour memory soak is recorded. These A/B/A runs cannot establish bounded memory.
  • top memory is not an allocation or leak trace. Missing GPU counters do not prove zero GPU work; whole-GPU and WindowServer figures include other applications.
  • High LinkLite CPU is measured. The criterion for materially lower CPU than Manager remains unresolved; memory savings do not satisfy it.
  • Handoffs require supervision. An outgoing driver left alive or a missing screen invalidates the comparison.
